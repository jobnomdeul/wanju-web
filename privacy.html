웹사이트 개인정보 안내

안내 기준일: 2026년 11월 22일

이 안내는 완주 앱을 소개하는 정적 웹사이트에 적용합니다. 향후 출시할 앱의 개인정보 처리방침과는 별도로 제공됩니다.

가상 체험과 데이터

이 사이트는 회원가입, 로그인, 문의 양식, 결제, 메일 구독 기능을 제공하지 않습니다. 이름·이메일·학교·공부 기록을 입력받거나 운영자 서버에 전송하지 않습니다.

계획 체크, 타이머, 날짜 선택, 스티커 전송 체험은 현재 탭의 메모리에서만 처리됩니다. 새로고침하거나 탭을 닫으면 초기화됩니다. 실제 친구에게 메시지를 전송하지 않습니다. 화면에 등장하는 인물·일정·기록은 가상 데이터입니다.

쿠키와 분석 도구

사이트 자체는 쿠키, 로컬 스토리지, 광고 추적, 방문 분석 도구를 사용하지 않습니다. 표시되는 캐릭터와 화면 파일은 같은 사이트에서 제공합니다. 기기 기본 글꼴을 사용합니다.

호스팅 서비스

이 사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 서비스의 보안 및 운영을 위해 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침과 GitHub Pages 안내에서 확인할 수 있습니다.

외부 링크와 문의

GitHub 등 외부 링크를 열면 해당 서비스의 정책이 적용됩니다. 사이트 관련 오류와 문의는 완주 웹사이트 GitHub 이슈에 남길 수 있습니다. 공개 게시판이므로 개인 연락처나 민감한 정보를 적지 마세요.

앱 출시 시 안내

앱의 계정·학습 기록·커뮤니티 운영에 필요한 정책과 권리 행사 방법은 실제 출시 전 별도의 앱 개인정보 처리방침과 이용약관으로 안내합니다.
