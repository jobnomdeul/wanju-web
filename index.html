지금 설치할 수 있나요?

현재 초대형 테스트 중입니다. iOS는 초대된 팀 계정으로 TestFlight에서, Android는 초대된 테스트 경로로 설치합니다. 정식 스토어 다운로드는 아직 제공하지 않아요.

모의평가 날짜는 어떻게 표시되나요?

목표 연도에 맞는 일정을 사용하며, 날짜를 확인하지 못한 시험은 ‘확인 중’으로 표시합니다. 앱에서 직접 수정할 수 있어요. 웹 체험은 실제 시험 일정과 무관한 가상 데이터입니다.

이 체험의 기록은 저장되나요?

현재 탭의 메모리에서만 사용하고 새로고침하면 초기화됩니다. 계정 생성·실제 게시·메일 발송·결제·AI 호출은 하지 않습니다. 별도의 분석 도구나 광고 추적 코드도 사용하지 않습니다.

앱에서는 어떻게 가입하나요?

만 14세 이상 사용자가 Google·Apple·이메일로 가입할 수 있습니다. 이 소개 웹에서는 가입이나 로그인 정보를 입력받지 않아요.
